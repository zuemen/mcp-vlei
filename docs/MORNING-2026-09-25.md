## 3. 台灣頁查證結果（對官員最關鍵）

| 說法 | 查證 |
|---|---|
| 行動工商憑證 2026-05-18 上線 | ✅ 經濟部新聞稿 122729 |
| 行動版「依網站、期限授權」 | ⚠️ **預告功能**（「將提供」）。目前行動憑證本身就是「附卡」 |
| 「財務、人事、業務部門」 | ⚠️ 中央社報導用語，不是經濟部原文 |
| IC 卡附卡授權 | ✅ 早就有，已導入 14 個系統；持卡人「仍以人為主」 |
| 授權給軟體／agent | ❌ 查無；工商憑證 CPS §3.2.7 伺服器應用軟體鑑別「不適用」 |
| 工商憑證在皮夾裡 | ❌ 查無；是另一個 App |
| 工商憑證跨境承認 | ❌ 查無；CPS §3.2.6「不適用」 |
| 皮夾技術棧 OpenID4VC、SD-JWT VC | ✅ 數發部官方 repo 確認（你貼的清單建議改成 ISO 18013-5，**不需要改**） |
| ISO 17442-3 | ✅ ISO 17442-3:2024 *Verifiable LEIs (vLEIs)*，2024-10 |
| 台灣 LEI | 有效 1,094 筆、失效 592 筆；**台灣沒有 LOU、也沒有 QVI**；LEI 紀錄的 registeredAs 就是**統一編號** |

**上台要小心的一點**：GLEIF 的資料把台灣標示為「Taiwan (Province of China)」。不要在投影片或 demo 放 GLEIF 查詢畫面。

回答「為什麼不用工商憑證」的核心（提案內有完整中英文）：兩者不衝突；工商憑證解決國內簽章，
vLEI 解決 agent 與境外；兩者用統一編號 ↔ LEI registeredAs 接起來。**不要說擴充已支援其他憑證 profile**——
程式只驗 vLEI。

## 5. 醒來後怎麼用

```bash
bash scripts/reset-demo.sh --keep-credentials   # 約 1 分鐘，READY
python scripts/rehearse.py                      # 約 1.5 分鐘，READY TO RECORD
# 然後照 docs/DEMO.md（或提案版）錄影
```

即時驗收：本機預設的 `python`（3.10）沒有裝 `mcp_vlei`，要在 repo 根目錄加 `PYTHONPATH=packages/mcp-vlei/src`（server 與 pytest 都要）。驗收會撤銷憑證，跑完按 console 的 `I` 或 `curl -X POST localhost:8800/reissue`。

要看草稿：直接開 `docs/slides/drafts/` 裡的兩份簡報，進第 13 頁會自動播。
